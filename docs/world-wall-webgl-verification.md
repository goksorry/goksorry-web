# 벽면 WebGL 정보판·풀뷰포트 게임 화면·일반모드 검증

2026-11-15. 광장 뒷벽의 정보를 캔버스 위 HTML 카드에서 WebGL 장면 안의 텍스처로 옮겼다. 헤더는 고정하고 장면이 나머지 화면을 모두 채운다. 상단바에 일반모드/메타버스모드 전환을 추가했다. [이전 DOM 벽면 검증](./world-wall-verification.md)의 "모달 없이 벽에서 원문 링크·필터 조작" 계약은 이 변경으로 대체된다.

## 바뀐 것

- 카메라: 사선에서 정면(yaw 0, 앙각 22°) orthographic으로 변경. 벽 x가 화면 x에 1:1로 대응해 벽면 판이 기울지 않는다. 화면 맞춤은 순수 함수 `wallFit`(`lib/world-wall.ts`)이 계산한다.
- 벽: 평평한 한 장, 높이 9. 중앙 아치·간판·셔터를 광장에서 제거하고 그 자리에 판 5개를 건다. 왼쪽 시장 지수 + 곡소리방, 중앙 삐에로 초상화 + 곡소리 지수, 오른쪽 곡소리 피드.
- 판 내용은 `CanvasTexture`로 그린다(`components/world/wall-painter.ts`). 삐에로는 원본 300×200 WebP를 그대로 텍스처로 쓰며 화면에서 정확히 3:2다. 크롭·재작화 없음.
- 벽 안에서는 스크롤·링크 클릭이 없다. 판을 누르면 판 위치에서 커지는 애니메이션과 함께 모달이 열린다. 삐에로·지수·시장 → 지수 탭, 피드 → 피드 탭(원문 링크·종목·출처 필터·더 보기), 곡소리방 → 곡소리방 탭(글쓰기·덧글).
- 클릭·키보드·스크린리더는 판 위에 겹친 투명 DOM 버튼과 숨김 텍스트가 맡는다(`WorldWallDom`). WebGL이 없으면(동작 줄이기·실패·로딩) 같은 섹션이 정적 배경 위 카드로 보인다.
- 레이아웃: 문서 스크롤 없음. 장면 내비·알림·극장 제어·다른 장면의 목록은 장면 안 HUD다. 면책 문구와 장면 이동 설명은 메뉴로 옮겼다.
- 화면 비율 기준 배치: 가로(폰 가로 포함)는 벽 전체, 세로·좁은 창은 벽 한 구역 확대 + 좌우 화살표 + 전체보기 토글.
- 일반모드: `/classic`이 메타버스 이전의 문서형 홈(시장·곡소리 지수 + 전체 피드)을 제공한다. `/`는 메타버스 그대로이며 canonical이다. 두 헤더의 전환 버튼은 `channels`·`stock` 범위를 유지한다.

## 한계

- 폰 가로(장면 높이 약 310–340px)는 벽 전체 보기에서 본문 11px이고 시장 지수 이름이 줄임표로 잘린다. 하단 장면 내비는 숨기고 메뉴의 장면 이동을 쓴다. 자세한 내용은 판을 눌러 모달로 본다.
- 세로 전체보기는 지도 수준이다(390px 폭에서 약 17 px/단위). 읽기용이 아니라 위치 확인·판 선택용이다.
- 곡소리방 글은 벽에서도 예쁜말 필터를 적용하지 않는다. 모달·`/goksorry-room`과 같은 표시다.
- 첫 방문 쿠키 동의창은 응답 전까지 하단 HUD를 가린다. 헤더와 벽 중앙은 가리지 않는다.
- 정면 카메라와 높아진 벽 때문에 다섯 장면 모두 모습이 바뀌었다.
- 마지막으로 고른 모드를 기억해 `/`에서 자동 분기하지는 않는다.
