# 메타버스·원본 삐에로 복원 검증

검증일: 2026-11-15. 기존 5단계 주식 삐에로 밈, 메타버스와 개미극장, 기본 좌우 피드를 유지하는 사용자 수정 요구를 반영했다. 이전 정적 통합 홈은 대체됐다.

## 로컬 결과

- TypeScript와 Next.js 프로덕션 빌드 통과. 홈 18 kB, First Load JS 141 kB. Three.js는 월드에 필요한 동적 로드로 복원했다.
- 최종 프로덕션 서버 대상 `test:world`: Chromium 48개, Firefox 44개 통과. Firefox의 실제 WebGL2 렌더 검사 4개는 실행 환경의 `AllowWebgl2:false` 때문에 생략한다. 총 92개 통과, 4개 환경 의존 생략.
- 기존 지수·시장 보정·시장 파싱·공개 API·인증 쿠키 등 25개 통과. 인증 세션·테마·모바일 메뉴·첫 방문 안내 8개 통과. 합계 125개 통과.
- 원본 5단계 × light/dark 10개 WebP는 `5690968`의 파일과 SHA-256이 모두 동일하다. 새 픽셀 SVG는 제거했다.
- 기존 지수 단계별 이미지·테마 전환, 극장 저장 시점에 따른 이미지 전환, 실제 원문 링크, 기본 좌우 열 배치와 중립 포함 최신순 통합 보기 확인.
- API 첫 500개 밖의 종목 120건을 범위 조회하고 추가 페이지를 이어 조회했다. 감성 필터 전환 후 집계 유지, 60초 갱신 시 펼친 페이지 유지, 실패 시 마지막 목록·실제 데이터 시각 보존 확인.
- 320/360/390/430/768px 가로 넘침 없음. 200% 기본 글자 확대, 키보드 메뉴·포커스 복귀, 데스크톱 페이지 스크롤 확인.
- Chromium 실제 WebGL에서 개미 이동·색상·감정 표현·숨김 탭 렌더 정지·극장 재생·PNG 저장 확인. Firefox는 정적 대체 무대와 PNG 저장 확인.
