# 곡소리 개미 월드

홈은 로그인 없이 탐색하는 개미 월드입니다. 장면은 광장·심리 전장·개미극장 셋이며, 광장 뒷벽의 두 문(왼쪽 심리 전장, 오른쪽 개미극장) 또는 하단 장면 버튼으로 이동합니다. 내 개미는 바닥 클릭·탭, 방향키로 이동합니다. 세로 화면의 구역 확대는 내 개미를 따라가며, 구역 화살표로 다른 구역을 보다가 다시 이동하면 내 개미가 있는 구역으로 돌아옵니다. 색상·감정 표현은 로컬 연출이며 분석 수치에 영향을 주지 않습니다. 다른 개미는 실제 접속자가 아니라 게시글 분위기를 나타내며 클릭 대상이 아닙니다(개미 위를 눌러도 바닥 클릭으로 이동). 광장의 개미는 쉬는 동안 자주 벽을 올려다보고, 곡소리 지수가 희망이면 중립·희망 개미의 표정이 밝아집니다.

## 장면과 정보

- 광장: 뒷벽에 시장 지수·곡소리방·삐에로·곡소리 지수·곡소리 피드와 커뮤니티 현황판(예전 재난방송)을 겁니다. 현황판은 커뮤니티마다 곡소리 지수, 공포·희망 비율 게이지, 표본 수, 수집 문제·소표본 상태를 보여 주고, 커뮤니티를 누르면 그 커뮤니티의 분위기와 근거 글이 열립니다. 지수 탭의 "커뮤니티 현황" 목록은 관심 종목까지 같은 내용을 보여 줍니다. 광장에 있을 때 커뮤니티 수집 문제가 새로 생기면 짧은 경보음을 냅니다(효과음을 켠 경우).
- 심리 전장: 선택 종목의 희망/공포 글 수와 비율로 병력·전선을 배치합니다. 종목은 최근 6시간 언급 순위(예전 개미 생태계, 상위 12종목)에서 고릅니다. 넓은 화면의 전장 판은 순위를 함께 보여 주고, 판을 누르면 진영과 순위 목록이 열립니다. 표본 3건 미만은 관찰 중, 방향성 글의 희망 또는 공포 비율이 65% 이상이면 희망 우세 또는 공포 우세, 나머지는 혼조입니다. 비율의 분모에서 중립을 제외하고, 중립 글은 별도 관찰석에서 엽니다. 새 대표 근거 글을 감지하면 지원군 도착 알림을 표시합니다. 가격·수익률 예측이 아닙니다.
- 극장: KST 하루 144개 10분 구간을 30초로 재생합니다. 누락·미래 구간은 비워 두며 보간하지 않습니다. 끝에서 마지막 저장 프레임의 PNG를 내려받거나 날짜가 포함된 극장 링크를 공유합니다. 링크는 최근 7일의 기록에 접근합니다.

기존 지수·피드 오버레이는 처음에 닫혀 있습니다. `channels` 또는 예전 `channel` 링크로 들어오면 해당 필터의 피드를 엽니다. 기존 메뉴의 피드 링크는 `feed=1`로 전체 피드를 엽니다. 데스크톱은 두 오버레이를 함께, 모바일은 전환 가능한 단일 하단 시트로 표시합니다. 필터·더 보기·원문·예쁜말 설정은 기존 컴포넌트를 사용합니다. 메뉴에서 로그인·프로필·테마·기존 사이트 메뉴·출처·정책에 접근합니다. Escape는 현재 패널을 닫고 포커스를 돌려줍니다.

`scene=battle|theater`, `stock=SYMBOL`, `date=YYYY-MM-DD`로 상태를 복원합니다. `plaza`가 기본 장면입니다. 예전 `scene=ecosystem` 링크는 심리 전장(`stock` 유지), `scene=broadcast` 링크는 광장으로 열리고 주소도 그에 맞게 바뀝니다. 날짜는 Asia/Seoul 기준 최근 7일만 허용합니다.

## 데이터 계약

`GET /api/internal/world`는 `WorldFrame` v1을 반환합니다. 서버에서 60초 캐시하고 화면은 60초마다 확인합니다. 전체 6시간 감성 결과를 페이지 단위로 읽고 게시글을 중복 제거합니다. 수집 정책상 제외한 출처와 알 수 없는 커뮤니티는 제외합니다. 집계와 상위 종목은 대표 글 목록의 크기에 의해 제한되지 않습니다.

프레임에는 생성 시각 `generated_at`, 실제 분석 기준 시각 `data_at`, 전체·커뮤니티·종목별 희망/공포/중립 건수, 방향성 비율, 기존 산식을 사용한 곡소리 지수, 분류별 최근 근거 글 3건, 수집 상태가 들어갑니다. 전체 지수는 기존 커뮤니티별 지수의 평균 산식을 재사용합니다. 종목 지수는 해당 글의 기존 감성 산식으로 구합니다. 공개 `/api/overview` 계약은 유지됩니다.

`data_at`이 30분 이상 오래되면 갱신 지연, 전체 표본이 3건 미만이면 관찰 중, 데이터가 없으면 대기 장면입니다. 읽기 실패는 503과 빈 대기 프레임을 반환합니다. 화면은 이미 받은 데이터를 보존하며 월드 조작·다른 정보 오버레이는 계속 제공합니다.

`GET /api/internal/world/replay?date=YYYY-MM-DD`는 KST 날짜의 `{date, timezone, slots}`를 반환합니다. `slots`는 144개의 `{bucket_at, frame}`이며 기록이 없으면 `frame: null`입니다. 잘못된 날짜·보관 범위 밖 날짜는 400, 기록 조회 실패는 503과 빈 슬롯을 반환합니다.

## 기록 적용

1. `npx supabase db push --workdir . --dry-run`으로 예정된 마이그레이션을 확인합니다.
2. 적용 대상이 맞으면 `npx supabase db push --workdir .`로 적용합니다.
3. 수집 워커가 기존 인증된 `POST /api/v1/detector/register`에 상태를 등록하면 웹 서버가 새 프레임을 만들고 기록합니다. 워커 변경은 필요하지 않습니다.

`world_snapshots.bucket_at`은 UTC 10분 경계의 기본키입니다. 같은 버킷은 upsert로 갱신합니다. 성공 후 7일 이전 기록을 삭제합니다. 방문자가 없어도 수집이 완료되면 기록됩니다. 이전 기간은 생성하지 않습니다. 기록은 서버 응답 전에 기다리며 기록용 DB 요청은 8초 후 중단합니다. 기록 실패는 별도 `world snapshot failed` 로그를 남기고 기존 수집 성공 응답을 유지합니다.

테이블은 RLS를 켜고 PUBLIC·anon·authenticated 권한을 회수하며 service_role만 읽기·쓰기를 허용합니다. 클라이언트에는 서비스 키를 전달하지 않습니다. [Supabase RLS 기준](https://supabase.com/docs/guides/database/postgres/row-level-security)을 따릅니다. CLI 마이그레이션, 번호 SQL 이력, 기준 스키마를 함께 관리합니다.

## 동작과 성능

장면은 필요할 때 로드합니다. SVG 개미의 애니메이션은 CSS, 내 개미 위치는 SVG 속성을 직접 갱신합니다. 애니메이션 프레임마다 React 상태를 갱신하지 않습니다. 방문자 아바타를 포함해 데스크톱 48, 모바일 24개 이내입니다. 실제 집계 규모는 숫자로 표시합니다.

효과음은 기본 무음이며 켜기 동작 이후 Web Audio로 발걸음·방송 신호·짧은 경보를 만듭니다. 색상·음소거는 기존 저장 레지스트리에 등록됩니다. 숨겨진 탭은 폴링·애니메이션·효과음을 중단합니다. 동작 줄이기에서는 정적 장면을 표시하며 극장은 시간 막대로 탐색합니다.

## 검증

`npm run test:world`는 테스트용 PostgREST 응답 서버와 Next 서버를 띄웁니다. 운영 Supabase를 사용하지 않습니다. 포트 3100·3101이 사용 중이면 먼저 별도 서버를 종료하세요. Chromium·Firefox 설치는 `npx playwright install chromium firefox`로 준비합니다.

- 집계·비율·표본·30분 지연 경계·상위 12종목·KST 경계·기록 중복·7일 보관 검증.
- 실제 Next API → Supabase 클라이언트 → 테스트 PostgREST → 응답 흐름으로 페이지 집계·register 인증·중복 upsert·기록 실패 격리·누락 구간 검증.
- Chromium·Firefox에서 세 장면·근거·아바타 이동·오버레이·모바일 시트·재생·탐색·PNG 파일·공유 링크·데이터 장애·동작 줄이기 검증.
- 최대 개미 상태에서 3초간 requestAnimationFrame 간격을 측정하고 `world-frame-cadence.json` 첨부. 모바일 수치는 모바일 크기 viewport이며 실물 기기 측정과 구분합니다.
- 임시 PostgreSQL: `psql "$WORLD_TEST_DATABASE_URL" -v ON_ERROR_STOP=1 -f tests/world-schema.sql`. 버킷 중복·제약·RLS·권한·7일 삭제를 SQL로 확인하고 롤백합니다.

홈의 프로그램형 레이아웃 전용 검사는 월드 검사로 교체했습니다. 다른 페이지의 테마 shell 검사는 로그인 페이지로 옮기고, 기존 피드·지수의 동작 검사는 오버레이를 연 상태에서 유지합니다.

검증 결과와 적용 범위: [로컬 검증 기록](./ant-world-verification.md).
