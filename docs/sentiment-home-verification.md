## 실제 데이터와 검증 경계

로컬 `.env.web`은 실행되지 않은 Supabase `127.0.0.1:54321`을 가리켜 직접 연결은 `ECONNREFUSED`였다. 환경 파일은 수정하지 않았다.

연결된 Supabase 도구의 읽기 전용 SQL로 운영 프로젝트 상태와 최근 6시간 표본 **411건**, 최신 분석 시각 **2026-11-15 05:20:25.537 UTC**를 확인했다. 운영 `/api/feed`의 모든 페이지에서 동일한 411건을 읽어, 임시 로컬 읽기 전용 응답 서버에 재현했다. 실제 글 화면 검토는 이 스냅샷을 사용하는 로컬 프로덕션 빌드에서 진행했다. 운영 DB에 테스트 데이터를 쓰거나 운영 수집·리포트 작업을 실행하지 않았다.

실제 글 스냅샷은 화면 검토 자료다. 운영 배포 및 새 웹 읽기 경로의 운영 DB 직접 접속까지 검증했다는 뜻은 아니다. 스냅샷 미리보기의 정책 테이블은 비어 있으므로 정책 내용이나 수집 정책별 지수 제외의 운영 상태를 이 화면으로 입증하지 않는다. 해당 제외 산식은 기존 함수와 격리 테스트로 검증했다.

최종 화면 캡처 시에는 시간 경과로 17건이 6시간 범위 밖으로 이동해 394건이 표시됐다. 수집 스냅샷 411건과 화면의 현재 시간 범위 집계는 구분한다.
