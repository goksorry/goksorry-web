# 메타버스 벽면 정보·개미 동작 검증

2026-11-15. 기존 메타버스·개미극장과 원본 5단계 주식 삐에로를 유지하면서, 광장에 실제 지수와 원문 피드를 직접 배치했다. 장식용 문구 대신 개미의 이동·멈춤·방향 전환으로 분위기를 표현한다.

## 로컬 결과

- `npx tsc --noEmit`, `npm run build`, `git diff --check` 통과. 홈 18.1 kB, First Load JS 141 kB. Three.js는 메타버스에 필요한 동적 로드를 유지한다.
- 프로덕션 서버의 월드·홈·API 검사: Chromium 51개, Firefox 47개 통과. 총 98개. 첫 실행에서 애니메이션 정지의 CSS 직렬화 예상값 때문에 실패한 2개는 예상값을 고친 뒤 양쪽 브라우저에서 재검증했다. Firefox WebGL2 제한으로 실제 렌더 검사 4개는 생략했다.
- 기존 지수·감성·시장 보정·시장 파싱·공개 API·인증 쿠키 검사 25개 통과.
- 테마·인증 검사 33개 통과: 프로덕션 모드 24개, 브라우저 API 모킹을 사용하는 개발 모드 9개. 채팅 서버 설정을 요구하는 2개는 생략했다. 개발 모드 검사 9개를 프로덕션 모드에서도 실행했을 때는 서버 초기 데이터, 서버 세션, CSS 압축값 차이로 실패했다. 해당 테스트의 원래 개발 모드에서 재검증했으며 애플리케이션의 인증·곡소리방 코드는 변경하지 않았다.
- 원본 light/dark 10개 WebP는 `5690968`과 바이트가 모두 동일하다. 5단계 지수·테마 전환과 극장 저장 프레임에 맞는 원본 선택을 확인했다.
- 지수·전체 피드·원문 링크가 처음부터 벽면에 노출되고, 기본 좌우 보기와 중립 포함 통합 보기가 같은 범위를 유지한다. 종목 선택·복수 출처·전체 복귀·뒤로 가기에서 모달 없이 집계와 목록이 갱신된다.
- 첫 500개 밖의 종목 120건을 조회하고 20건씩 끝까지 이어 불러왔다. 감성 필터는 집계 비율을 바꾸지 않는다. 빈 결과·중립만 있는 범위·소표본·60초 갱신·갱신 실패 시 마지막 목록과 실제 기준 시각 보존을 확인했다.
- 320/360/390/430/768px 가로 넘침 없음. 360×640에서 동의창 처리 후 지수·원본 삐에로·첫 원문 제목이 보인다. 기본 글자 크기의 지수판은 211px. 200% 글자 확대, 키보드 탐색·메뉴·포커스 복귀 확인.
- 혼조 개미 두 마리의 시차·실제 CSS 이동, 화면 밖·숨김 탭 정지, 동작 줄이기 정지 자세 확인. Chromium 월드 이동·장면 전환·극장 재생·PNG 저장·숨김 탭 렌더 정지 확인. Firefox는 정적 대체 장면과 PNG 저장 확인.
